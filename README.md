# Meow.zip

> 길고양이 케어테이커들을 위한 돌봄 일지 서비스 입니다.

## Tech Stack

TypeScript | Next.js | Jotai | Tanstack-Query | TailwindCSS | shadcn-ui

## 주요 기능

### 1. 고양이 모음집

- 길고양이 프로필 등록 및 관리
- 고양이별 상세 정보 기록
- 이미지 업로드 및 관리

### 2. 돌봄 일지

- 일별 돌봄 활동 기록
- 사진 첨부 기능
- 돌봄 히스토리 관리

### 3. 함께 돌봄

- 다른 케어테이커와 협업
- 돌봄 일정 공유
- 실시간 알림

### 4. 커뮤니티

- 피드 작성 및 공유
- 댓글 기능
- 좋아요/북마크 기능
- 사용자간 커뮤니티 소통

### 5. 알림

- 알림 기능
- 알림 관리

> 개발 기간: 2023.10 ~ 진행 중
